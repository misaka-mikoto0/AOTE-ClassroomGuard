# AOTE - 实力主义至上的一体机管控系统

> All-in-One of the Elite (AOTE) Classroom Guardian System

班级大屏幕一体机非上课时段使用管控系统。作为后台守护程序，在非上课时间自动限制设备使用（冻结浏览器、视频播放器、游戏平台等），仅允许通过**数学挑战**或**授权U盘**临时解锁，引导学生合理使用设备。

## 🎯 项目背景

班级配备的大屏幕一体机（交互式电子白板/教学一体机）在非上课时间常被用于播放与学习无关的视频内容。本系统作为后台守护程序，在非上课时段自动限制设备使用，仅允许通过特定方式（数学挑战或授权U盘）临时解锁。

系统核心理念：**实力主义至上** —— 想用电脑？先做对一道数学题。

## ✨ 功能特性

### 核心模块

| 模块 | 说明 |
|------|------|
| ⏰ **时间调度 (Time Guard)** | 根据课程表自动判断上课/下课时间，切换严格/宽松/紧急三种模式；支持节假日例外配置 |
| 🎯 **进程猎手 (Process Hunter)** | 0.5秒周期扫描并冻结目标进程（浏览器/视频/游戏）；三重冻结：线程挂起 + 窗口隐藏 + Job Object |
| 🧮 **数学挑战 (Math Challenge)** | 答对数学题获得临时解锁权限；**四位数运算，结果为10位数**；做题期间自动冻结计算器、浏览器等工具 |
| 🔑 **U盘授权 (USB Guard)** | 双因素认证（硬件ID + 密钥文件SHA-256）；支持「即拔即禁 / 定时解锁 / 维护模式」 |
| 🛡️ **防绕过 (Anti-Tamper)** | 双进程互相守护（3秒复活）；注册表+计划任务多重自启动；扩展心跳检测 |
| 🌐 **HTTP服务** | 本地 `127.0.0.1:8765`；`/ping` 心跳、`/kill` 违禁内容上报（供浏览器扩展） |
| 📊 **系统托盘** | 状态显示、临时解锁、触发数学挑战、紧急退出入口 |
| 📝 **日志系统** | 按天轮转；记录模式切换/进程冻结/数学挑战/U盘事件/防绕过触发 |

### 数学挑战亮点

- **难度一**（解锁 5 分钟）：三个四位数连乘，结果为10位数
  ```
  例: 3862 × 2158 × 1051 = 8,759,239,996
  ```
- **难度二**（解锁 10 分钟）：加减乘除混合运算，结果为10位数
  ```
  例: (9198 - 3154) × 1469 × 1033 = 9,171,630,988
  ```
- **防作弊**：做题期间自动冻结 `calc.exe`、所有浏览器、`mathway.exe`、`photomath.exe`、`wolframalpha.exe` 等工具
- **防绕过**：窗口置顶最大化、禁用关闭按钮、拦截 Alt+F4/Esc

### 技术栈

- **语言**：Python 3.10+
- **进程管理**：`psutil`、`pywin32` (Windows API: SuspendThread / ShowWindow / Job Object)
- **Web服务**：`flask` / 内置 `http.server`
- **GUI**：`tkinter`（数学挑战窗口、U盘模式选择、密码验证）
- **托盘**：`pystray` + `Pillow`
- **配置**：`PyYAML`（支持热重载）
- **打包**：`PyInstaller`

### 运行模式

| 模式 | 触发条件 | 行为 |
|------|---------|------|
| 严格模式 | 非上课时间 | 冻结所有目标进程，禁止浏览器/视频软件运行 |
| 宽松模式 | 上课时间 | 不冻结进程，仅通过浏览器扩展进行内容过滤 |
| 紧急模式 | 扩展失效/守护进程被攻击 | 无条件冻结所有浏览器进程 |

## 📦 安装指南

### 环境要求

- **操作系统**：Windows 10/11 x64（专业版/教育版/企业版）
- **运行权限**：必须以管理员身份运行（UAC 提升）
- **Python**：3.10+

### 安装步骤

1. **克隆仓库**

   ```bash
   git clone https://github.com/<your-account>/AOTE-ClassroomGuard.git
   cd AOTE-ClassroomGuard
   ```

2. **创建虚拟环境（推荐）**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. **安装依赖**

   ```powershell
   pip install -r requirements.txt
   ```

4. **运行测试**（可选，验证安装）

   ```powershell
   python test_suite.py
   ```

## 🚀 使用说明

### 启动系统

以**管理员身份**运行 PowerShell，执行：

```powershell
python main.py
```

启动后：
- 系统托盘出现蓝色盾牌图标
- 自动按课程表进入对应模式
- 非上课时间检测到目标进程 → 自动弹出数学挑战窗口

### 命令行参数

| 参数 | 说明 |
|------|------|
| `python main.py` | 标准模式（主进程 + 自动启动守护子进程） |
| `python main.py --watchdog` | 仅守护进程模式（无UI，监控主进程） |
| `python main.py --daemon` | 后台模式（等同 --main） |
| `python main.py --respawn-check` | 计划任务用（检查进程是否存在，不在则复活） |
| `python uninstall.py` | 完整卸载清理 |

### 解锁方式

#### 方式一：数学挑战

非上课时间运行浏览器等目标程序时，系统自动弹出置顶数学挑战窗口：
1. 选择难度（难度一5分钟 / 难度二10分钟）
2. 计算并输入答案（10位整数）
3. 答对 → 获得对应时长临时解锁；答错 → 更换新题继续

#### 方式二：授权U盘

插入授权U盘后弹出模式选择：
- **即拔即禁**：U盘拔出前保持解锁，拔出后3秒内恢复严格模式
- **定时解锁**：30分钟 / 1小时 / 2小时，到期自动恢复
- **维护模式**：需管理员密码二次确认，解锁至下次重启

### 紧急退出

- 快捷键：`Ctrl + Shift + Alt + G`
- 或托盘右键 → 「紧急退出系统」
- 输入管理员密码验证通过后完全退出

## ⚙️ 配置说明

所有配置集中在 [config/config.yaml](config/config.yaml)，支持**热重载**（修改后5秒内生效，无需重启）。

关键配置项：

```yaml
# 课程表（按星期配置时间段）
schedule:
  weekday:
    1: [["08:00", "12:00"], ["14:00", "17:30"]]

# 数学挑战参数（四位数运算，结果10位数）
math_challenge:
  question_params:
    min_number: 1000
    max_number: 9999
    result_min: 1000000000
    result_max: 9999999999

# U盘授权（需替换为实际值）
usb_guard:
  whitelist_serials: ["你的U盘序列号"]
  key_hash_sha256: "密钥文件的SHA-256哈希"

# 管理员密码（SHA-256哈希）
emergency:
  admin_password_hash: "你的密码SHA-256哈希"
```

### 生成密钥哈希

```python
import hashlib
print(hashlib.sha256("你的密码".encode()).hexdigest())
print(hashlib.sha256(open("U盘密钥文件路径","rb").read()).hexdigest())
```
